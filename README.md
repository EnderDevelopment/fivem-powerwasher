# PowerWash

PowerWash is a FiveM resource that allows players to spawn and remove a power washer object in-game. This resource is useful for roleplay servers where players need a power washer for cleaning tasks. The power washer is spawned at the player's location and can be removed with a simple command.

## Install

1. Download the PowerWash resource from the GitHub repository.
2. Extract the downloaded file into your FiveM server's `resources` directory.
3. Add `ensure PowerWash` to your `server.cfg` file to start the resource automatically when the server launches.

## Use

1. Connect to your FiveM server.
2. In the chat, type `/powerwasher spawn` to spawn the power washer at your current location.
3. To remove the power washer, type `/powerwasher remove` in the chat.
